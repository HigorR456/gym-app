# Product Overview

## Goal

Build a mobile gym workout management and execution app, with a **local-first / offline-first** architecture, allowing the user to create exercises, workouts, and training programs; schedule them on a calendar; and execute workouts with set tracking, load, reps/time, rest, and a session timer.
